# Adding another project

1. Create a folder such as `projects/ecg-learning-tool/`.
2. Extract the project's files into that folder while preserving all subfolders and filenames, including names beginning with a dot. Avoid uploading all extracted files into a single flat folder.
3. Keep its `package.json`, lockfile, source, assets, and tests together. Each app can use different development dependencies.
4. Add the project to the repository README table and add a working link in the root `index.html`.
5. If it has automated checks, add its workflow under the repository-level `.github/workflows/`. Point the workflow's working directory and dependency-cache path to the new project. Workflow files inside a nested project folder are not used as repository workflows.
6. If it should appear on the shared Pages site, extend `scripts/build-site.mjs` to build that app and copy its static output to `_site/projects/<project-name>/`. Give each app a separate URL path and use relative asset links where supported.

Run project commands from that project's folder. The repository root is an index, not a shared Node package. Commit the new app on a branch and open a pull request into `main`.

The first project in this collection is HEART. The ECG learning tool is not copied or generated by this reorganization.
